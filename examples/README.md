# Synthetic examples｜合成範例

example_5species_all_regions.csv 延續原專案的五物種範例：28 筆合成紀錄、20 個座標、5 個分群，包含臺灣、金門、馬祖、澎湖及其他離島。所有學名與點位僅供操作測試，不能當成採集或分布紀錄。

在資料頁匯入 CSV，選擇經度 longitude、緯度 latitude、分群 species；範圍選「臺灣與離島」。locality、region_hint 和 notes 可保留於資料表。也可在「輸出 → 完整專案存檔」開啟 example_project.tbm.json，直接恢復示範配置；此專案保留示範資料標記。

The example contains 28 synthetic rows, 20 coordinates and five groups across Taiwan and its offshore islands. These are operational examples, not occurrence evidence. Import the CSV, map longitude/latitude/species, and select the Taiwan-with-offshore-islands extent. The remaining fields are retained. Alternatively, open example_project.tbm.json through Export → Complete project to restore the demonstration setup; its demo-data flag is retained.
